# 官方 CLI 与安全接入

核验日期：2026-10-09。来源：[Tripo CLI 官方文档](https://developers.tripo3d.ai/zh/docs/cli)。此页是流程知识；文档核实不等于安装、登录或收费调用已获批。

## API Key 与可选设备授权路线

API 支持直接在 Authorization 中使用 Bearer API Key，不需要 CLI，也不要求浏览器登录。用户已有 API Key 时，“必须再登录”不是 Tripo 的技术要求。以下设备授权仅是可选接入方法，不能把执行环境的权限或秘密处理限制说成 API 限制。

官方 CLI 要求 Node.js 20+；其发布的安装命令是 `npm install -g tripo-cli`。`tripo login` 发起浏览器设备授权：用户本人登录、核对浏览器与终端验证码一致，再确认。成功登录把凭证与区域保存在命名 profile；`tripo doctor` 检查认证、网络和余额。没有必要让用户把 API Key 发到聊天中。

官方支持多 profile；TRIPO_API_KEY 环境变量优先于 profile。不要因为已有 profile 就断言当前使用了正确账户。登录前检查环境变量是否存在即可，禁止输出其值。完成后通过安全、不泄露秘密的诊断核实身份/区域与就绪情况。

## 本项目执行门槛

在安装之前取得对应环境的安装授权；在建立持续访问之前取得该次明确确认。用户亲自完成官方设备授权页。未获批准时，不安装、不发起登录、不生成。设备授权不可用而跳转 API Key 页面时，停下来给用户受支持的安全接入办法，不读取/复制网页密钥，不改走聊天或命令行明文密钥。

截至此次文档更新的状态：CLI 未安装；用户已说明有 API Key、无需登录，并要求继续读教程。不要催促登录、反复要求安装确认或擅自建立持续访问。继续授权范围内的只读研究和无凭据请求计划；不调用聊天中的密钥。未来状态变化应按用户最新明确指令核实，不把这段当永久限制。

## 用 CLI 也须精确控制费用

安装后先读当前 `tripo docs --topic commands/make` 与 `tripo docs --topic examples/game-asset`，确认版本、参数和预设实际展开。CLI 自动选择流程或 preset 可能带来额外处理步骤，不能把一个命令误算为一次收费任务。首轮使用经过预算核对的显式流程；不给不明链路加 --yes，不默认执行 redo、batch、topup 或 texture/convert/rig 链。

CLI 文档说明 make/task watch 会等待结果；使用它们时不要再重复启动任务或实现一套并行收费流程。失败/超时后保留 task_id，按 [API 说明](api-v3.md) 与 [账单规则](billing.md) 查既有任务。检查原始模型与可用预览后再决定下一步，不能为了“看起来更好”自动重跑。

官方 profile/历史目录、环境文件和任何临时授权链接都不进入项目、源码包或截图。审计日志只存脱敏参数、task_id、输出哈希与已核实用量。
