# 可选航路短途：单武器逐关构筑

更新：2026-10-07 UTC。本文是战斗产品方向、默认输入与状态冲突的唯一提案/实施契约。当前实现状态、验证和阻断只在 [AI_BOARD](../../AI_BOARD.md) 记录。上位规则见[执行硬约束](../../.ai/instructions/execution-and-visual-constraints.md)；底层模块说明放各自技术文档，不复制本提案。

## 已由作者明确的方向

- 实施可选动作短局，以“爬塔”的逐关推进与抽卡构筑形式选自己的风格；不要求建筑真是一座塔
- 与既有雾港、航路遗迹、冷雾暖灯及人物生活叙事自然衔接，不突然切成霓虹竞技场
- 玩家只用一种武器，不扩武器切换或装备刷取；具体武器外观尚未定型
- 卡牌围绕攻击速度、范围与特效；有强化普通攻击与强化蓄力攻击的风格，可以构筑组合
- 一般攻击范围强化只是适度延长近战距离；攻击图形和判定距离必须一致
- 蓄力可通过明确的形态转化卡变成可重复使用的远程攻击，仍是同一武器
- 近瞬蓄力可以与有限次目标间突进连斩组合，形成迅速连贯的穿行斩击；采用原创命名和动作，不复制商业资源
- 有独立防御按钮，并可构筑精准防御后反斩的风格，不照搬复杂槽位、搓招体系
- 作者已明确批准继续实施。制作分阶段，不把设想或纯数据测试称为真实战斗完成

## 上位边界

剧情、关系表达、固定衣装与身体生活时间不靠战斗刷取或解锁。固定16套衣装保持直接可用，角色与立绘仍共享衣装状态。短途失败、退出或不参加，都保留主线、关系与衣装；本局强化不自动写入持久主线。

所有基础攻击和防御动作默认可用，卡牌强化风格而不是凑齐几张才可玩。没有付费抽卡、货币卡包、稀有度刷取或装备库存。本轮无血腥表现，只操作星遥，不加入四人战斗AI。

## 当前可调实现默认值

以下是实施建议，不等于作者逐项固定批准的数值：

- 短局先以约5–10分钟为设计目标，首个验证只有一处现有港路衍生遭遇区与一种原创失控雾灯机关
- 每过一关，从仍有效的卡中随机展示最多3张，选择1张；首批卡池控制在6–9张，显示当前值→选择后的值或明确形态变化
- 强化在本局累积，下局重新选择。作者所说“常驻远程”当前解释为本局持续，不假设已批准跨局永久解锁
- 若剩余有效卡不足3张，展示实际有效数量；没有有效卡时直接给出继续选项，不能死锁或发无效满级卡
- 逐关的关数、攻击/蓄力/格挡时窗、减伤、射程等由数据限定、可调，当前数值不是完成平衡的承诺
- 普通点击攻击；按住进入蓄力、松开释放。按下即给可见准备动作，不同时把长按解释成自动普攻连发；需要真实手感复核短按响应和攻速收益
- 键盘J/K采用最近移动方向；鼠标左右键朝点击位置瞄准。进入菜单的旧指针不持续覆盖键盘朝向。
- 独立防御：按下进入有方向的格挡，长按保持，松开解除。精准反击默认建议是按下后的短窗口内受击触发，过窗仍普通格挡；自动反斩还是二次攻击输入可调整
- 闪避/冲刺保留独立输入，短无敌和冷却有上限，不靠卡牌叠成无限无敌

## 三类构筑与效果关系

1. 普攻：提高普通攻击节奏、适度范围和清晰的挥击表现，不取消所有恢复时间
2. 蓄力：缩短蓄势或加强重击范围；形态卡可选择远程蓄力或目标间链斩。先采用远程与链斩互斥的明确模式，避免同次释放无序叠加；若以后允许复合，必须单独定义效果链与预算
3. 防反：精准时机受击后的反斩、适度反击范围与成功后短攻速收益。基本格挡与基础精准窗口不依赖抽卡才存在

近战范围卡不会隐式变成远程。远程转化有有限射程、速度、穿透数量，需蓄力、无第二武器及弹药库存。链斩的目标数、搜敌半径、锁定时刻和总持续时间有明确上限；无目标、目标死亡或消失时安全结束，不能穿墙追击或递归触发自身。

## 状态冲突与命中契约

- 单个战斗状态机决定当前动作，画面只展示结果。持久故事的唯一写入口与本局临时状态的唯一写入口隔离，不让UI直接写HP、卡牌或存档
- 防御可中断未释放的攻击准备/蓄力，并按明确规则中止链斩；松开、暂停、失焦、退出和场景更换都清掉挂起输入，不自动恢复一记旧攻击
- 普攻/蓄力/反斩已释放后的恢复不被防御缩短；恢复中按住防御可在恢复结束衔接，精准窗口仍从原按下计时，结束时不刷新。受击/冲刺阶段不新增输入缓冲。
- 同次按下只开一次精准窗口；长按不逐帧刷新，重复按下和抖动不能白拿新窗口；同一攻击实例对同一目标最多结算一次
- 攻击、反斩、弹体与次级特效有独立来源标记，反斩/链斩/弹体的衍生效果不能无限触发另一层反斩
- 敌方预警、有效命中和恢复阶段可读，视觉弧线/范围圈依据同一派生属性，不画大打小或打到图形以外
- 命中停顿有总预算，多目标命中不线性叠成卡死；视觉停顿与固定逻辑tick/输入窗口分开
- 旧局ID、旧revision、重复选择与旧回调被拒或幂等回放；退出后所有弹体/预警/动作回调结束，不能污染下一局或主线

## 与剧情、生活空间相接

沿用既有回声潮、航灯网络与群岛航路。短途的具体目标是照应航路、查看受潮干扰的机关，让远处船只顺利靠岸；灯塔可出现，不把所有地图做成重复塔层。

出发前留整理外套和表达边界的简短交流，关间是可休息/可返回的安全停靠，返航后回到现有船舱喝茶、换装和继续完整关系戏。可称“招式领悟”等世界内包装，但卡面仍清楚写出实际数值和效果。

跨数月的身体体验只在预编写章节间推进。重复局不催快HRT，不刷好感，不重复发生同一场家庭冲突。重要故事可直接以叙事演出继续，不要求重新打过遭遇区。

## 分阶段落实

- A：独立本局规则、派生统计、有效卡抽样、输入不变/快照隔离与真实临时存档隔离测试
- B：同一港路场地的一敌闭环：移动、普攻、蓄力、冲刺、格挡、精准防反，原创动作/预警/命中与退出
- C：逐关选卡，明确的属性变化和主线返回；无有效卡、失败、暂停/失焦、重入等边界
- D：同切片增量验证远程蓄力和短蓄链斩，包括墙阻挡、目标失效、命中去重与效果预算

每阶段均须实际引擎运行；无图形测试不能替代手感。先把一处可信、精致的视觉与交互切片做好，再讨论扩场地或敌型。
