# 启动存档保护源码检查点（2026-10-08）

## 范围

本检查点以远端 `b7f9343998ff291bfba8c6fe7611697edbfe569d` 的完整 156 文件树为基线，只保全可独立测试的应用层、存档适配器及快照 UI。它不发布新重建世界，也不修改默认工程入口。

- `SavePort.probe_snapshot()` 与 `FileSave.probe_snapshot()` 提供只读探测。仅正式槽和备份均不存在才报告无存档；损坏、可恢复与未知版本均保留启动选择。
- `StateStore.saved_game_status()` 提供隔离摘要，不更换当前状态或写入文件。
- `GameFlow` 的第五个可选构造参数 `startup_gate` 默认为 `false`，保留原调用兼容性。显式启用后，有存档时只接受继续或经两步确认的新游戏；其他剧情、保存、移动锚点和菜单输入被拒绝。
- 继续沿用双阶段恢复：场景准备前验证，准备完成时重新读取并比较同一快照。失败、取消、过期回执和在途文件变化不会清除启动保护。
- 快照 UI 展示继续、重试、新游戏及取消；确认页默认焦点在取消。文字明确说明后续手动保存及换场自动保存会替换原槽和备份。
- 字体生成与覆盖检查包含适配器错误文案。保留已改名 `Foglight UI SC`、来源记录与完整 OFL；不新增游戏运行时依赖。
