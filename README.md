# 雾灯归航（暂定）

以高细节 3D 雾港环境和 2D 像素角色呈现的原创自由叙事探索游戏，含可选轻量 roguelite 路线与事件，计划在 Steam 免费发行。

作者已授权在 dot 云端电脑持续开发至可交付试玩版；当前实现、构建与验证状态只以 [AI_BOARD](AI_BOARD.md) 的可核实记录为准。首章设计基线为 Windows PC 首验、离线单人、预编写剧情，一个关卡三个分区，目标 10–15 分钟。人物年龄与成年身份是待作者确认的虚构前提，内容边界为非露骨、无血腥。
