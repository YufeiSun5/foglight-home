# 雾灯归航（暂定）

2026-10-06 实施交接：当前实施分支包含尚未完成验收的 Godot WIP。作者要求停止 Mac 开发、迁往云端，并否定占位港口的美术质量。当前目标为叙事探索、衣柜与可选轻量路线，取消强制解谜/刷材料/战斗。详见 [Mac WIP 交接与实际验证](docs/playtest/mac-wip-handoff.md)。下方原初始化基线尚待系统修订，不代表当前实现已通过。

以 3D 雾港环境和 2D 角色呈现的原创叙事解谜游戏，计划在 Steam 免费发行。

当前仓库仅有设计与协作文档，没有可玩游戏、Godot 工程或已验证的发行包。已批准的首章设计基线为 Windows PC 首验、离线单人、预编写剧情，一个关卡三个分区，目标 10–15 分钟；实现尚未开始。人物年龄与成年身份是待作者确认的虚构前提，内容边界为非露骨、无血腥。
